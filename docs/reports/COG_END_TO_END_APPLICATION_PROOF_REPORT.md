## 3. Deployment & Applicability Decision Matrix

### When to Use Cog (High Justification)
- **Safety-Critical Systems**: Clinical informatics, aerospace/autonomous robotics, nuclear/grid infrastructure.
- **Regulatory & Audit Governance**: FDA SaMD Part 11, HIPAA, financial ledger compliance, legal discovery.
- **Multi-Stakeholder Dispute Resolution**: Systems with conflicting evidence where disagreement must be preserved rather than collapsed.
- **Longitudinal State Evolution**: Systems requiring multi-month conceptual continuity and assumption drift tracking.

### When NOT to Use Cog (Overhead Exceeds Value)
- **Trivial / Low-Stakes Tasks**: Conversational chat, creative writing, basic code formatting, ad-hoc exploratory searches.
- **Static CRUD Operations**: Standard database read/writes with no epistemic ambiguity.
- **Ephemeral Scripts**: One-off throwaway data manipulation scripts.
